## 适用范围

本说明覆盖后台列表接口统一分页规范。

所有接口默认都挂在 `/api` 下。

## 1. 统一分页参数

所有已支持分页的列表接口统一支持：

```text
page
page_size
```

默认值：

- `page = 1`
- `page_size = 20`

## 2. 统一分页返回结构

已支持分页的列表接口统一返回：

```json
{
  "items": [],
  "total": 100,
  "page": 1,
  "page_size": 20
}
```

## 3. 已完成分页的接口

### 后台账号列表

GET /users

### 经销商列表

```http
GET /dealers
```

### 师傅列表

```http

```

### 任务列表

```http
GET /tasks
```

### 客户列表

```http
GET /customers
```

### 角色列表

```http
GET /system/roles
```

### 操作日志列表

```http
GET /system/operation-logs
```

### HQ 审核任务列表

```http
GET /hq/review/tasks
```

### 通知列表

```http
GET /notices
```

### 任务附件列表

```http
GET /tasks/{id}/attachments
```

说明：

- 当前后端已兼容返回普通任务附件 + 现场实据
- 返回项新增 `source` 字段：`attachment` 表示普通附件，`evidence` 表示现场实据
- 如果页面本身就是“现场照片/视频/环境记录”主列表，仍建议优先调用 `GET /tasks/{id}/evidences`

### 任务实据列表

```http
GET /tasks/{id}/evidences
```

## 4. 查询示例

```http
GET /users?page=1&page_size=20
GET /dealers?page=2&page_size=10
GET /tasks?page=1&page_size=50
GET /system/roles?page=1&page_size=20
GET /notices?page=1&page_size=20
```

## 5. 前端接法

### 请求参数

统一传：

```ts
{
  page: current,
  page_size: pageSize,
}
```

### 表格映射

- 数据源：`items`
- 总条数：`total`
- 当前页：`page`
- 每页条数：`page_size`

## 6. 兼容说明

如果前端不传 `page/page_size`，后端仍会返回第一页数据，默认每页 20 条。
