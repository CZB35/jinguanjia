# 项目设置前端对接文档

本文档用于前端对接后台“系统设置 > 项目设置”模块。

## 1. 功能目标

后台可按不同项目（服务类型）配置以下内容：

- 轮播图/示例图
- 合格要求
- 温馨提示
- 启用状态

当前项目（服务类型）包括：

- `measure`：量尺服务
- `install`：安装服务
- `ironing`：熨烫服务
- `cleaning`：除尘除螨服务

## 2. 权限与菜单

### 菜单权限

- 权限 key：`settings:project-settings`
- 菜单名称：`项目设置`

前端菜单可挂在：

- `系统设置`
  - `项目设置`

## 3. 查询项目设置

### 接口

- `GET /api/system/project-settings`

### 查询参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `service_type` | string | 否 | 传则只返回单个项目配置；不传返回全部 |

### 请求示例

```http
GET /api/system/project-settings
```

或：

```http
GET /api/system/project-settings?service_type=measure
```

### 返回结构

```json
{
  "items": [
    {
      "service_type": "measure",
      "title": "量尺服务",
      "banner_image_url": "/uploads/project-settings/measure-banner.png",
      "requirement_content": "1. 照片中能清晰识别出施工工具\n2. ...",
      "warm_tip_content": "请确保照片清晰可见，光线充足。所有照片将自动添加时间、地点、门店等水印信息。",
      "status": "enabled"
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `service_type` | string | 项目标识：`measure/install/ironing/cleaning` |
| `title` | string | 项目标题 |
| `banner_image_url` | string | 顶部示例图，可直接访问的 `/uploads/...` 路径 |
| `requirement_content` | string | 合格要求，建议前端支持多行文本展示 |
| `warm_tip_content` | string | 温馨提示，建议前端支持多行文本展示 |
| `status` | string | `enabled` / `disabled` |

## 4. 保存项目设置

### 接口

- `PATCH /api/system/project-settings`

### 请求体

```json
{
  "items": [
    {
      "service_type": "measure",
      "title": "量尺服务",
      "banner_image_url": "/uploads/project-settings/measure-banner.png",
      "requirement_content": "1. 照片中能清晰识别出施工工具\n2. 冲击钻及钻头\n3. 螺丝刀等工具",
      "warm_tip_content": "请确保照片清晰可见，光线充足。所有照片将自动添加时间、地点、门店等水印信息。",
      "status": "enabled"
    },
    {
      "service_type": "install",
      "title": "安装服务",
      "banner_image_url": "/uploads/project-settings/install-banner.png",
      "requirement_content": "安装类要求...",
      "warm_tip_content": "安装类温馨提示...",
      "status": "enabled"
    }
  ]
}
```

### 请求字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `items` | array | 是 | 要保存的项目配置列表 |
| `items[].service_type` | string | 是 | `measure/install/ironing/cleaning` |
| `items[].title` | string | 否 | 项目标题，不传时后端会回退默认中文名 |
| `items[].banner_image_url` | string | 否 | 示例图 URL，通常来自上传接口返回 |
| `items[].requirement_content` | string | 否 | 合格要求 |
| `items[].warm_tip_content` | string | 否 | 温馨提示 |
| `items[].status` | string | 否 | `enabled/disabled` 或 `启用/禁用` |

### 成功返回

```json
{
  "ok": true
}
```

## 5. 图片上传建议

当前后端没有单独做“项目设置图片上传”专用接口。

建议前端复用通用上传能力，最终拿到 `/uploads/...` 路径后再写入 `banner_image_url`。

如果后续需要，我方可以再补一个专用上传接口，例如：

- `POST /api/system/project-settings/upload`

目前此接口 **尚未提供**。

## 6. 前端页面建议

建议页面结构：

1. 顶部项目 tab：
   - 量尺服务
   - 安装服务
   - 熨烫服务
   - 除尘除螨服务
2. 每个 tab 对应一组配置：
   - 轮播图/示例图上传
   - 合格要求富文本或多行文本
   - 温馨提示富文本或多行文本
   - 启用/禁用状态
3. 统一点击“保存”提交当前或全部项目配置

## 7. 小程序展示侧建议

小程序“检核照片标准”页可通过 `service_type` 取对应项目配置：

1. 顶部图片用 `banner_image_url`
2. 标题用 `title`
3. 合格要求用 `requirement_content`
4. 温馨提示用 `warm_tip_content`

如果项目状态为 `disabled`，前端可：

- 不展示该项目配置
- 或回退到默认文案

## 8. 注意事项

1. `service_type` 必须是固定枚举：`measure/install/ironing/cleaning`
2. 图片字段只存 URL，不直接存文件二进制
3. 文本内容建议支持换行，前端显示时保留换行效果
4. 当前项目设置存储在 `system_config`，按 `project_setting:{service_type}` 区分
