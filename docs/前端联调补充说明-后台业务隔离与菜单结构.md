## 适用范围

本说明覆盖最近这批后台隔离改动：

- 后台登录与业务端登录分离
- 后台账号管理与经销商管理分离
- 角色管理页隐藏业务角色
- 权限树菜单分组调整

所有接口默认都挂在 `/api` 下。

## 1. 后台登录接口

后台管理端请改用：

```http
POST /auth/login/admin
```

说明：

- 仅允许后台角色登录：
  - `super_admin`
  - `hq_reviewer`
- `dealer`
- `technician`
  不能再用后台登录入口

原通用登录接口：

```http
POST /auth/login/password
```

继续留给业务端/小程序端使用。

## 2. 后台账号管理与经销商管理分离

### 后台账号管理

仍使用：

- `GET /users`
- `POST /users`
- `GET /users/{id}`
- `PATCH /users/{id}`
- `PATCH /users/{id}/status`
- `POST /users/{id}/reset-password`

说明：

- 这里只允许后台账号
- 后台角色只允许：
  - `super_admin`
  - `hq_reviewer`
- 如果传入：
  - `dealer`
  - `technician`
  会返回：

```text
后台账号仅允许分配后台管理角色
```

### 经销商管理

新增后台接口：

- `GET /dealers`
- `POST /dealers`
- `GET /dealers/{id}`
- `PATCH /dealers/{id}`

说明：

- 前端“经销商管理”页不要再调 `/users`
- 应改为调 `/dealers`

### 经销商新增示例

```json
{
  "name": "白迪",
  "mobile": "18838962531",
  "password": "123456",
  "store_ids": [2],
  "status": "enabled"
}
```

## 3. 角色管理页

接口：

```http
GET /system/roles
```

后端现在已隐藏业务角色：

- `dealer`
- `technician`

所以后台角色管理页只展示后台角色。

## 4. 权限树菜单结构调整

接口：

```http
GET /system/permission-tree
```

当前后端返回结构调整为：

### 系统设置

- 角色管理
- 权限管理

### 基础信息

- 门店信息
- 客户来源
- 项目设置
- 短信开关配置
- 隐私协议
- 用户协议

说明：

- 后端现在会把原来挂在 `系统设置` 下的：
  - 项目设置
  - 隐私协议
  - 用户协议
  - 短信开关配置
  统一重组到 `基础信息` 下返回

### 额外说明

权限树里的“短信开关配置”当前是后端虚拟菜单节点，前端可直接按返回的 `permission_code` 渲染：

```text
settings:sms-switch
```

## 5. 短信开关配置

平台配置键：

- `sms.switch.dealer_notify`
- `sms.switch.customer_review`

建议前端菜单放在：

```text
基础信息 -> 短信开关配置
```

并继续通过：

```http
GET /system/configs
PATCH /system/configs
```

读写这两个配置。

## 6. 前端最小改动清单

1. 后台登录页改用：

```http
POST /auth/login/admin
```

2. 经销商管理页接口改为：

- `GET /dealers`
- `POST /dealers`
- `GET /dealers/{id}`
- `PATCH /dealers/{id}`

3. 后台账号管理页继续用 `/users`，但不要再拿它创建经销商/师傅。

4. 角色管理页直接用 `/system/roles` 返回结果，不再期待 `dealer / technician` 出现。

5. 权限树菜单按新的父子关系渲染：

- `系统设置`
- `基础信息`
