# 师傅端接口文档

## 1. 基本信息

- 端：师傅端
- 接口前缀：`/api`
- 当前状态：`已实现` + `已完成冒烟测试`

## 2. 通用返回结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | number | 业务码，`0` 表示成功 |
| `message` | string | 返回消息 |
| `data` | object | 业务数据 |
| `request_id` | string | 请求追踪 ID |

## 3. 页面与接口

### 3.1 登录页

- `POST /auth/login/password`：密码登录
- `POST /auth/code/send`：发送验证码
- `POST /auth/login/code`：验证码登录

关键字段与经销商端一致。

补充说明：

1. `role_code` 可不传
2. 后端返回 `roles`、`current_role`、`switchable`
3. 单角色师傅账号通常返回：`roles=["technician"]`、`switchable=false`
4. 请求头需要带：`Authorization: Bearer <access_token>`
5. 如果当前端是师傅独立登录页，也可以固定传 `role_code=technician`

### 3.2 工作台

#### 3.2.1 工作台首页

- 接口：`GET /technician/dashboard`
- 状态：`已实现` `已测试`

查询字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `year` | number | 可选，年份筛选 |
| `month` | number | 可选，月份筛选 |

调用示例：

```http
GET /api/technician/dashboard?year=2026&month=4
```

返回字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `pending_task_count` | number | 待处理任务数 |
| `pending_review_task_count` | number | 待评价任务数 |
| `month_completed_count` | number | 本月完成数 |
| `recent_tasks` | array | 最近任务 |
| `service_group_counts` | array | 按服务类型统计 |
