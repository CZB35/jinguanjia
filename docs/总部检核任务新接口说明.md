## 适用范围

本文档只说明总部检核任务新增的两个列表接口。

所有接口默认都挂在 `/api` 下。

## 1. 新接口一：待评价 + 已完成

接口：

```http
GET /hq/review/tasks/pending-and-completed
```

### 用途

返回总部检核视角下：

- 待评价
- 待评分
- 已完成

这三类任务/服务环节。

### 状态范围

任务状态命中：

- `pending_dealer_review`
- `pending_hq_score`
- `completed`

服务环节状态命中：

- `pending_dealer_review`
- `pending_hq_score`
- `completed`

### 分页参数

支持：

```text
page
page_size
```

默认：

- `page = 1`
- `page_size = 20`

### 请求示例

```http
GET /hq/review/tasks/pending-and-completed?page=1&page_size=20
Authorization: Bearer <token>
```

## 2. 新接口二：待执行 + 进行中

接口：

```http
GET /hq/review/tasks/pending-execute-and-executing
```

### 用途

返回总部检核视角下：

- 待执行
- 进行中

这两类任务/服务环节。

### 状态范围

任务状态命中：

- `pending_execute`
- `executing`

服务环节状态命中：

- `pending_execute`
- `executing`

### 分页参数

支持：

```text
page
page_size
```

默认：

- `page = 1`
- `page_size = 20`

### 请求示例

```http
GET /hq/review/tasks/pending-execute-and-executing?page=1&page_size=20
Authorization: Bearer <token>
```

## 4. 权限要求

当前只允许以下后台角色访问：

- `super_admin`
- `hq_reviewer`
