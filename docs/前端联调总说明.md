## 适用范围

本说明汇总最近这一轮后端联调改动，供前端统一对接参考。

覆盖内容：

- 后台登录与角色隔离
- 后台账号 / 经销商 / 师傅管理
- 重置密码
- 列表分页
- 工作台统计与趋势图
- 任务列表排序与服务轨迹
- 任务详情补充字段
- 短信与客户评价链接
- 服务号 H5 绑定接口

所有接口默认都挂在 `/api` 下。

## 1. 后台登录与角色隔离

### 后台登录

使用：

```http
POST /auth/login/admin
```

说明：

- 后台账号使用 `账号 + 密码` 登录
- 仅允许后台角色登录：
  - `super_admin`
  - `hq_reviewer`

请求示例：

```json
{
  "account": "admin",
  "password": "yy123456!"
}
```

说明：

- 后端兼容 `username`
- 业务端不要再用后台登录接口

### 业务端通用登录

继续使用：

```http
POST /auth/login/password
```

说明：

- 业务端仍按手机号体系登录
- 经销商、师傅、小程序端继续用这个接口

### 角色管理

接口：

```http
GET /system/roles
```

当前变化：

- 后端已隐藏业务角色：
  - `dealer`
  - `technician`

后台角色管理页只展示后台角色。

## 2. 后台账号 / 经销商 / 师傅管理

### 后台账号管理

接口：

- `GET /users`
- `POST /users`
- `GET /users/{id}`
- `PATCH /users/{id}`
- `PATCH /users/{id}/status`
- `POST /users/{id}/reset-password`

字段口径：

- `account`：后台登录账号
- `mobile`：管理员电话
- `name`：姓名
- `role_names_text`：所属角色（中文）

列表映射：

- “姓名” -> `name`
- “账号” -> `account`
- “管理员电话” -> `mobile`
- “所属角色” -> `role_names_text`

### 经销商管理

不要再用 `/users` 创建经销商，改用：

- `GET /dealers`
- `POST /dealers`
- `GET /dealers/{id}`
- `PATCH /dealers/{id}`
- `POST /dealers/{id}/reset-password`

新增经销商请求示例：

```json
{
  "name": "白迪",
  "mobile": "18838962531",
  "password": "123456",
  "store_ids": [2],
  "status": "enabled"
}
```

说明：

- `password` 可不填
- 不填默认密码：`123456`

### 师傅管理

使用：

- `GET /technicians`
- `POST /technicians`
- `GET /technicians/{id}`
- `PATCH /technicians/{id}`
- `PATCH /technicians/{id}/status`
- `POST /technicians/{id}/reset-password`

## 3. 重置密码

### 经销商

```http
POST /dealers/{id}/reset-password
```

### 师傅

```http
POST /technicians/{id}/reset-password
```

行为：

- 前端不用传新密码
- 后端直接重置为：

```text
123456
```

返回示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "ok": true,
    "default_password": "123456"
  }
}
```

前端交互建议：

- 操作列增加：`重置密码`
- 点击后弹二次确认：

```text
是否确认重置密码？重置后默认密码为 123456
```

  "page_size": 20

## 6. 工作台与趋势图

### 工作台顶部四卡

接口：

- `GET /dealer/dashboard`
- `GET /hq/dashboard`
- `GET /technician/dashboard`

新增字段：

```json
service_overview_cards
```

每项结构：

```json
{
  "service_type": "measure",
  "title": "量尺任务",
  "total_count": 102,
  "completion_rate": 95.0
}
```

### 任务完成趋势对比

新增查询参数：

```text
trend_mode=week | month | year
```

新增返回字段：

```json
task_trend_compare
```

每项结构：

```json
{
  "period": "周一",
  "completed_count": 0,
  "total_count": 0
}
```

映射关系：

- `已完成任务` -> `completed_count`
- `任务总量` -> `total_count`
- X轴 -> `period`

标签规则：

- `week`：`周一 ~ 周日`
- `month`：`1日 ~ 30日`
- `year`：`1月 ~ 12月`

## 7. 任务列表与任务详情

### 任务列表排序

接口：

```http
GET /tasks
```

当前后端已调整为：

- 最新订单默认在前
- 按 `appointment_time` 倒序

前端不要再自行重排旧数据。

### 服务轨迹 / 任务日志

接口：

```http
GET /tasks/{id}/logs
```

后端 `action` 已改成中文展示文案，例如：

- `创建任务`
- `分派任务`
- `技师开始执行任务`
- `技师提交检核`
- `客户评价：非常好`
- `总部评分完成`

前端直接展示 `action`，不要再自己翻译英文动作码。

### 任务详情新增字段

接口：

```http
GET /tasks/{id}
```

新增字段：

- `customer_review`
- `hq_score`

用于经销商端任务详情展示。

新增公开绑定接口：

- `POST /wechat/bind-url`
- `POST /wechat/bind/code/send`
- `POST /wechat/bind/confirm`

## 10. 中文展示原则

展示层统一使用中文字段，不要直接展示英文代码值。

推荐直接展示的中文字段：

- `role_names_text`
- 权限树里的 `title`
- 操作日志里的 `action`
- 各类 `status_text`
- `task_status_text`
- `display_status_text`
- `review_status_text`
- `score_status_text`

不要直接展示的英文标识：

- `role_code`
- `permission_code`
- `service_type`
- `status_code`
