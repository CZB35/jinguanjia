## 适用范围

本说明覆盖后台管理端最近这批接口和文案变更：

- 后台账号管理
- 经销商管理
- 师傅管理
- 重置密码操作
- 权限树文案调整

所有接口默认都挂在 `/api` 下。

## 1. 后台账号管理

接口：

- `GET /users`
- `POST /users`
- `GET /users/{id}`
- `PATCH /users/{id}`
- `PATCH /users/{id}/status`
- `POST /users/{id}/reset-password`

### 字段口径

- `name`：姓名
- `account`：账号
- `mobile`：管理员电话
- `role_names_text`：所属角色

### 列表页字段映射

- “姓名” -> `name`
- “账号” -> `account`
- “管理员电话” -> `mobile`
- “所属角色” -> `role_names_text`

## 2. 经销商管理

经销商管理页不要再调 `/users`，请改用：

- `GET /dealers`
- `POST /dealers`
- `GET /dealers/{id}`
- `PATCH /dealers/{id}`
- `POST /dealers/{id}/reset-password`

### 新增经销商

请求示例：

```json
{
  "name": "白迪",
  "mobile": "18838962531",
  "password": "123456",
  "store_ids": [2],
  "status": "enabled"
}
```

### 密码说明

- `password` 可不填
- 不填时后端默认密码为：

```text
123456
```

前端新增页文案建议：

```text
请设置密码，不填则默认密码 123456
```

## 3. 师傅管理

师傅管理继续使用：

- `GET /technicians`
- `POST /technicians`
- `GET /technicians/{id}`
- `PATCH /technicians/{id}`
- `PATCH /technicians/{id}/status`
- `POST /technicians/{id}/reset-password`

## 4. 重置密码

### 经销商

```http
POST /dealers/{id}/reset-password
```

### 师傅

```http
POST /technicians/{id}/reset-password
```

### 行为

- 前端不用传新密码
- 后端直接重置为：

```text
123456
```

返回示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "ok": true,
    "default_password": "123456"
  }
}
```

### 前端交互建议

操作列增加：

- `重置密码`

点击后弹二次确认：

```text
是否确认重置密码？重置后默认密码为 123456
```

成功提示：

```text
密码已重置为 123456
```

## 5. 权限树文案

接口：

```http
GET /system/permission-tree
```

### 当前文案调整

原来：

- `权限管理`

现在：

- `账号管理`

前端菜单和权限树请直接使用后端返回的 `title`。

## 6. 菜单结构

### 系统设置

- 角色管理
- 账号管理

### 基础信息

- 门店信息
- 客户来源
- 项目设置
- 短信开关配置
- 隐私协议
- 用户协议

## 7. 前端最小改动清单

1. 后台账号管理页：

- “账号”列读 `account`
- “所属角色”列读 `role_names_text`

2. 经销商管理页：

- 新增/编辑/详情/重置密码改走 `/dealers`

3. 师傅管理页：

- 操作列补 `重置密码`
- 调 `/technicians/{id}/reset-password`

4. 经销商管理页操作列也补：

- `重置密码`
- 调 `/dealers/{id}/reset-password`

5. 权限树和菜单文案：

- 直接按 `/system/permission-tree` 返回渲染，不要再写死“权限管理”旧文案。
