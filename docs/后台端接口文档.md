# 后台端接口文档

## 1. 基本信息

- 端：后台端（总部检核 + 管理后台）
- 接口前缀：`/api`
- 当前状态：`已实现` + `已完成冒烟测试`

## 2. 通用返回结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | number | 业务码，`0` 表示成功 |
| `message` | string | 返回消息 |
| `data` | object | 业务数据 |
| `request_id` | string | 请求追踪 ID |

## 3. 页面与接口

### 3.1 登录与角色

- `POST /auth/login/password`
- `POST /auth/login/code`
- `POST /auth/code/send`
- `POST /auth/refresh`
- `POST /auth/logout`
- `GET /auth/me`
- `POST /auth/switch-role`

状态：全部 `已实现` `已测试`

登录补充说明：

1. 后台端也可以不传 `role_code`，后端会按优先级选默认角色
2. 如果账号支持多个角色，响应会返回：
   - `roles`
   - `current_role`
   - `switchable`
3. 访问受保护接口时，请求头格式必须是：`Authorization: Bearer <access_token>`
4. 如果后台登录页固定区分管理员角色，也可以显式传 `role_code=super_admin`
