## 适用场景

用于经销商小程序内点击“绑定通知”后，跳转 H5 页面完成服务号绑定。

目标：

- 用户在微信里完成服务号授权
- 用户输入手机号 + 短信验证码确认绑定
- 后端把当前微信用户 `openid` 绑定到系统账号

所有接口默认都挂在 `/api` 下。

## 1. 整体流程

前端推荐流程：

1. 小程序点击“绑定通知”
2. 打开 H5 页面，例如：

```text
https://service.ryds.cn/mobile/wechat-bind/index.html
```

3. H5 页面先调 `POST /wechat/bind-url`
4. 后端返回 `bind_token` 和微信授权地址 `bind_url`
5. H5 页面跳转到 `bind_url`
6. 微信授权后回调后端 `/wechat/service-account/callback`
7. 后端再重定向回 H5 页面，并带上 `bind_token` 和 `authorized=true`
8. H5 页面展示手机号验证码表单
9. 用户获取验证码并确认绑定
10. 绑定成功后提示返回小程序

## 2. 获取绑定授权链接

接口：

```http
POST /wechat/bind-url
Content-Type: application/json
```

请求体：

```json
{
  "return_url": "https://service.ryds.cn/mobile/wechat-bind/index.html"
}
```

说明：

- `return_url` 传当前 H5 页地址即可
- 后端会把它缓存起来，微信授权成功后回跳到这里

返回示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "bind_token": "e9e9b9c6-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "bind_url": "https://open.weixin.qq.com/connect/oauth2/authorize?..."
  }
}
```

前端处理：

- 保存 `bind_token`
- 直接跳转 `bind_url`

## 3. 微信授权回跳

微信回调地址由后端处理：

```text
https://service.ryds.cn/api/wechat/service-account/callback
```

前端不用自己调这个接口。

### 回跳结果

如果是 H5 绑定流程，后端会 302 重定向回你传入的 `return_url`，并带上参数：

```text
?bind_token=xxx&authorized=true
```

示例：

```text
https://service.ryds.cn/mobile/wechat-bind/index.html?bind_token=xxx&authorized=true
```

前端处理：

- 检查 URL 上是否有 `authorized=true`
- 有的话进入“手机号验证码绑定”步骤

## 4. 发送绑定验证码

接口：

```http
POST /wechat/bind/code/send
Content-Type: application/json
```

请求体：

```json
{
  "mobile": "18838962531"
}
```

返回成功示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "ok": true
  }
}
```

错误场景：

- 手机号为空
- 账号不存在
- 账号被禁用
- 60 秒内重复发送
- 阿里云短信发送失败

前端建议：

- 成功后开始 60 秒倒计时
- 失败时直接提示后端返回的 `message`

## 5. 确认绑定

接口：

```http
POST /wechat/bind/confirm
Content-Type: application/json
```

请求体：

```json
{
  "bind_token": "e9e9b9c6-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "mobile": "18838962531",
  "code": "123456"
}
```

返回成功示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "ok": true,
    "user_id": 2,
    "wechat_bound": true
  }
}
```

前端处理：

- 提示“绑定成功”
- 提供“返回小程序”按钮

## 6. 常见错误与前端处理

### 1. 用户还没完成微信授权

后端可能返回：

```text
请先在微信内完成授权
```

前端处理：

- 引导用户重新走授权流程

### 2. 微信授权状态失效

后端可能返回：

```text
微信授权状态已失效，请重新发起绑定
```

或：

```text
微信授权状态已过期，请重新发起绑定
```

前端处理：

- 清掉本地 `bind_token`
- 重新调用 `POST /wechat/bind-url`

### 3. 短信验证码错误或过期

后端可能返回：

- `验证码错误`
- `验证码已过期，请重新获取`

前端处理：

- 提示用户重新输入或重新获取验证码

## 7. 已登录后台绑定接口

如果是已登录用户在系统内自己点“绑定微信”，仍然用原接口：

```http
GET /me/wechat-bind-url
GET /me/wechat-binding
```

这和 H5 自助绑定是两套并存流程，不冲突。

## 8. 前端最小改动清单

H5 绑定页至少需要：

1. 页面初始化调用 `POST /wechat/bind-url`
2. 跳转微信授权 `bind_url`
3. 回跳后识别 URL 参数 `authorized=true`
4. 手机号输入框
5. 获取验证码按钮，对接 `POST /wechat/bind/code/send`
6. 验证码输入框
7. 确认绑定按钮，对接 `POST /wechat/bind/confirm`
8. 成功提示与返回小程序按钮
