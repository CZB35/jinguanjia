# 环节记录管理选中导出接口前端对接说明

本文说明后台 `环节记录管理` 页面勾选记录后导出的接口。接口默认挂在 `/api` 下，需携带后台登录 token。

## 接口信息

```http
POST /api/hq/review/tasks/export/selected
Authorization: Bearer <token>
Content-Type: application/json
```

用途：只导出当前页面勾选的环节记录。

返回：XLSX 文件流，不是 JSON。

```http
Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
Content-Disposition: attachment; filename="review-tasks-export.xlsx"
```

## 请求体

按任务 ID 导出：

```json
{
  "task_ids": [35, 36]
}
```

兼容字段：

| 字段 | 说明 |
| --- | --- |
| `task_ids` / `taskIds` / `ids` | 任务 ID。前端可直接传列表行里的 `task_id` 或 `id` |
| `service_item_ids` / `serviceItemIds` | 服务环节 ID。若页面按具体环节勾选，优先传这个字段 |

如果两个字段都为空，后端返回：

```text
task_ids或service_item_ids不能为空
```

如果没有匹配到可导出记录，后端返回：

```text
所选记录暂无可导出数据
```

## 导出内容

文本列固定为：

```text
客户手机号,客户姓名,任务类型,师傅姓名,师傅手机号,师傅评分,门店,经销商名称,经销商评价,客户评价,客户地址,师傅定位地址
```

图片列按实际现场图片数量动态追加：

- 单张图片：`附件图片`
- 多张图片：`附件图片1`、`附件图片2`、`附件图片3` ...

图片是真实嵌入 XLSX 的压缩图片，不是图片链接；图片来源为师傅现场上传后的带水印文件。

## 前端调用示例

```ts
const selectedIds = selectedRows.map(row => row.task_id || row.id)

const res = await request.post(
  '/api/hq/review/tasks/export/selected',
  { task_ids: selectedIds },
  { responseType: 'blob' },
)

downloadBlob(res.data, 'review-tasks-export.xlsx')
```

如果列表行提供 `service_item_id`：

```ts
const serviceItemIds = selectedRows
  .map(row => row.service_item_id)
  .filter(Boolean)

const res = await request.post(
  '/api/hq/review/tasks/export/selected',
  { service_item_ids: serviceItemIds },
  { responseType: 'blob' },
)
```

## 注意事项

- 不要在前端自行拼 CSV，否则会丢失内嵌图片和后端中文字段转换。
- 文件名优先读取响应头 `Content-Disposition`。
- 如果只想导出当前筛选结果，不按勾选项导出，继续使用 `GET /api/hq/review/tasks/export`。
