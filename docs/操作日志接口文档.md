## 适用范围

本文档只说明系统设置中的“操作日志”接口。

所有接口默认都挂在 `/api` 下。

## 1. 操作日志列表

接口：

```http
GET /system/operation-logs
```

### 请求参数

支持分页参数：

```text
operator_id
operator_name
page
page_size
```

默认值：

- `page = 1`
- `page_size = 20`

### 请求示例

```http
GET /system/operation-logs?page=1&page_size=20
Authorization: Bearer <token>
```

按操作人筛选示例：

```http
GET /system/operation-logs?operator_name=张三&page=1&page_size=20
GET /system/operation-logs?operator_id=12&page=1&page_size=20
```

### 返回结构

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "id": 1,
        "biz_type": "task",
        "biz_id": 19,
        "action": "submit_task",
        "operator_id": 12,
        "operator_name": "张三",
        "operator_role": "technician",
        "remark": "短信联调提交",
        "created_at": "2026-06-11 14:34:48"
      }
    ],
    "total": 100,
    "page": 1,
    "page_size": 20
  },
  "request_id": "..."
}
```

### 字段说明

- `id`：日志主键
- `biz_type`：业务类型，例如 `task`
- `biz_id`：业务主键 ID
- `action`：操作动作
- `operator_id`：操作人 ID
- `operator_name`：操作人姓名
- `operator_role`：操作人角色
- `remark`：备注说明
- `created_at`：操作时间

## 2. 操作日志详情

接口：

```http
GET /system/operation-logs/{id}
```

### 请求示例

```http
GET /system/operation-logs/1
Authorization: Bearer <token>
```

### 返回结构

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "biz_type": "task",
    "biz_id": 19,
    "action": "submit_task",
    "operator_id": 12,
    "operator_name": "张三",
    "operator_role": "technician",
    "remark": "短信联调提交",
    "created_at": "2026-06-11 14:34:48"
  },
  "request_id": "..."
}
```

## 3. 权限要求

这两个接口都要求后台管理权限，当前允许角色：

- `super_admin`
- `hq_reviewer`

业务端角色不能访问。

## 4. 前端接法

### 列表页

- 数据源：`data.items`
- 总条数：`data.total`
- 当前页：`data.page`
- 每页条数：`data.page_size`

### 详情弹窗 / 抽屉

点击某条日志后，调用：

```http
GET /system/operation-logs/{id}
```

直接展示返回的：

- `biz_type`
- `biz_id`
- `action`
- `operator_id`
- `operator_name`
- `operator_role`
- `remark`
- `created_at`

## 5. 当前说明

当前后端已支持：

- 分页查询操作日志列表
- 查看单条操作日志详情
- 关键任务操作审计
- 后台删除用户 / 批量删除用户审计
- 后台新增账号 / 编辑账号 / 重置密码审计
- 后台新增经销商 / 编辑经销商 / 重置密码审计
- 后台重置师傅密码审计

如果后续还要补：

- 按业务类型筛选
- 按时间范围筛选

可以在此基础上继续扩展查询参数。
