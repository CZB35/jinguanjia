# 客户短信评价端接口文档

## 1. 基本信息

- 端：客户短信评价端
- 接口前缀：`/api`
- 当前状态：`已实现` + `已完成冒烟测试`

说明：

1. 客户短信评价端不使用账号登录
2. 通过 `token` 访问表单、上传图片、提交评价

## 2. 通用返回结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | number | 业务码，`0` 表示成功 |
| `message` | string | 返回消息 |
| `data` | object | 业务数据 |
| `request_id` | string | 请求追踪 ID |

## 3. 页面与接口

### 3.1 发送评价链接

- 接口：`POST /customer-reviews/send-link`
- 状态：`已实现` `已测试`

请求字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `task_id` | number | 任务 ID |

返回字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `ok` | boolean | 是否成功 |
| `token` | string | 评价令牌 |
| `url` | string | 表单访问地址 |

### 3.2 评价表单页

- 接口：`GET /customer-reviews/form`
- 状态：`已实现` `已测试`

查询字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `token` | string | 评价令牌 |

返回字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `task_id` | number | 任务 ID |
| `customer_id` | number | 客户 ID |
| `expired_at` | string | 过期时间 |
| `status` | string | 链接状态 |
| `technician_name` | string | 师傅姓名 |
| `technician_avatar_url` | string | 师傅头像 |
| `technician_avg_score` | number | 师傅平均分 |
| `service_items_text` | string | 服务项目中文文案 |
| `service_time` | string | 服务时间 |
| `tag_options` | string[] | 可选标签 |
| `images` | array | 已上传图片 |
| `images[].id` | number | 图片 ID |
| `images[].file_name` | string | 文件名 |
| `images[].file_url` | string | 可直接访问的文件路径，格式如 `/uploads/customer-reviews/...` |

### 3.3 上传评价图片

- 接口：`POST /customer-reviews/images`
- 状态：`已实现` `已测试`

查询字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `token` | string | 评价令牌 |

表单字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `file` | file | 图片文件 |

返回字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 图片 ID |
| `file_name` | string | 文件名 |
| `file_url` | string | 可直接访问的文件路径，格式如 `/uploads/customer-reviews/...` |

### 3.4 删除评价图片

- 接口：`DELETE /customer-reviews/images/{id}`
- 状态：`已实现` `已测试`

查询字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `token` | string | 评价令牌 |

### 3.5 提交评价

- 接口：`POST /customer-reviews/submit`
- 状态：`已实现` `已测试`

请求字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `token` | string | 评价令牌 |
| `star` | number | 星级，1-5 |
| `tags` | string[] | 标签 |
| `content` | string | 评价内容 |
| `image_ids` | number[] | 已上传图片 ID 列表 |

返回字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `ok` | boolean | 是否提交成功 |

### 3.6 评价详情页

- 接口：`GET /customer-reviews/detail`
- 状态：`已实现` `已测试`

查询字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `token` | string | 评价令牌 |

返回字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `review_id` | number | 评价 ID |
| `task_id` | number | 任务 ID |
| `customer_id` | number | 客户 ID |
| `star` | number | 星级 |
| `tags` | string[] | 标签 |
| `content` | string | 评价内容 |
| `images` | array | 图片列表 |
| `images[].id` | number | 图片 ID |
| `images[].file_name` | string | 文件名 |
| `images[].file_url` | string | 可直接访问的文件路径，格式如 `/uploads/customer-reviews/...` |
| `created_at` | string | 创建时间 |
