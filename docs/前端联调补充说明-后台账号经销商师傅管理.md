## 适用范围

本说明覆盖后台管理端这批最近变更：

- 后台登录与业务端登录分离
- 后台账号管理与经销商管理分离
- 师傅/经销商支持重置密码
- 权限树文案和菜单结构调整

所有接口默认都挂在 `/api` 下。

## 1. 后台登录

后台管理端请使用：

```http
POST /auth/login/admin
```

说明：

- 仅允许后台角色登录：
  - `super_admin`
  - `hq_reviewer`
- 不要再用通用登录接口做后台登录

## 2. 后台账号管理

接口：

- `GET /users`
- `POST /users`
- `GET /users/{id}`
- `PATCH /users/{id}`
- `PATCH /users/{id}/status`
- `POST /users/{id}/reset-password`

说明：

- 这里只管理后台账号
- 账号新增/编辑时只允许后台角色
- “账号”列请读后端返回的：

```json
account
```

- “所属角色”列请读：

```json
role_names_text
```

## 3. 经销商管理

经销商管理页不要再调 `/users`，改用：

- `GET /dealers`
- `POST /dealers`
- `GET /dealers/{id}`
- `PATCH /dealers/{id}`
- `POST /dealers/{id}/reset-password`

### 新增经销商请求示例

```json
{
  "name": "白迪",
  "mobile": "18838962531",
  "password": "123456",
  "store_ids": [2],
  "status": "enabled"
}
```

### 密码说明

- `password` 可不填
- 不填时后端默认密码：

```text
123456
```

前端文案建议：

```text
请设置密码，不填则默认密码 123456
```

## 4. 师傅管理

师傅管理继续使用：

- `GET /technicians`
- `POST /technicians`
- `GET /technicians/{id}`
- `PATCH /technicians/{id}`
- `PATCH /technicians/{id}/status`
- `POST /technicians/{id}/reset-password`

## 5. 经销商 / 师傅重置密码

### 经销商

```http
POST /dealers/{id}/reset-password
```

### 师傅

```http
POST /technicians/{id}/reset-password
```

### 行为

- 前端不需要传密码
- 后端直接重置为：

```text
123456
```

返回示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "ok": true,
    "default_password": "123456"
  }
}
```

### 前端交互建议

操作列增加：

- `重置密码`

点击后弹二次确认：

```text
是否确认重置密码？重置后默认密码为 123456
```

成功后提示：

```text
密码已重置为 123456
```

## 6. 权限树文案和菜单结构

接口：

```http
GET /system/permission-tree
```

### 当前结构

#### 系统设置

- 角色管理
- 账号管理

#### 基础信息

- 门店信息
- 客户来源
- 项目设置
- 短信开关配置
- 隐私协议
- 用户协议

### 说明

后端已将原来权限树里的：

- `权限管理`

文案改为：

- `账号管理`

前端权限树直接使用返回的 `title` 渲染即可。

## 7. 前端最小改动清单

1. 后台登录页改用：

```http
POST /auth/login/admin
```

2. 后台账号管理页继续用 `/users`

3. 经销商管理页改用 `/dealers`

4. 师傅管理页在操作列增加：

- `重置密码`

5. 经销商管理页在操作列增加：

- `重置密码`

6. 权限树和左侧菜单文案按 `/system/permission-tree` 返回渲染，不要再写死旧文案“权限管理”。
