# 环节记录管理导出前端对接说明

本文说明后台 `环节记录管理` 页面的导出对接方式。接口默认挂在 `/api` 下，需携带后台登录 token。

## 1. 问题背景

当前页面下载出的文件名为 `hq-review-records.csv`，表头是 `record_id、task_id、task_no` 等英文列名。

这不是后端导出接口返回的文件。后端真实导出接口返回的是中文表头 XLSX，文件名为 `review-tasks-export.xlsx`。

前端不要再用当前表格数据自行 `Blob` 拼 CSV，否则会出现英文表头、字段遗漏、状态值不一致、现场图片无法嵌入等问题。

## 2. 导出接口

```http
GET /api/hq/review/tasks/export
Authorization: Bearer <token>
```

用途：导出环节记录管理列表数据，返回 XLSX 文件流。

响应头示例：

```http
Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
Content-Disposition: attachment; filename="review-tasks-export.xlsx"
```

## 3. 支持的筛选参数

导出时应透传页面当前筛选条件。

| 参数 | 说明 | 示例 |
| --- | --- | --- |
| `task_type` | 任务类型，支持单项、三专、四专 | `量尺`、`三专` |
| `serviceType` | 服务类型别名，兼容旧前端 | `measure` |
| `scoreStatus` | 检核状态 | `pending`、`scored` |
| `inspection_status` | 检核状态别名 | `待核验`、`已核验` |
| `storeId` | 所属门店 ID | `1` |
| `technicianId` | 服务师傅 ID | `39` |
| `customer_mobile` | 客户手机号 | `17796854338` |
| `customerMobile` | 客户手机号别名 | `17796854338` |
| `startDate` | 预约开始日期 | `2026-06-01` |
| `endDate` | 预约结束日期 | `2026-06-30` |

示例：

```http
GET /api/hq/review/tasks/export?customer_mobile=17796854338&scoreStatus=scored
```

## 4. 导出列

后端返回中文表头，当前文本列包括：

```text
客户手机号,客户姓名,任务类型,师傅姓名,师傅手机号,师傅评分,门店,经销商名称,经销商评价,客户评价,客户地址,师傅定位地址
```

其中：

- `客户地址` 是任务客户地址。
- `师傅定位地址` 是师傅上传现场图片/视频时传入的位置；为空表示师傅端未传定位。
- `任务类型` 由后端转为中文。
- `附件图片1`、`附件图片2` 等图片列按实际现场图片数量动态追加，单图时列名为 `附件图片`。
- 附件图片是真实嵌入 XLSX 的压缩图片，不是图片链接；图片来自师傅现场上传后的带水印文件。

## 5. 前端处理要求

点击 `批量导出` 时：

1. 调用 `GET /api/hq/review/tasks/export`。
2. 将当前筛选条件拼到 query string。
3. 使用响应文件流下载。
4. 文件名优先读取 `Content-Disposition`。
5. 不要前端自己遍历表格数据生成 CSV。

错误示例：

```ts
// 不要这样做：会导出英文 key，也无法插入现场图片
const csv = rows.map(row => Object.values(row).join(',')).join('\n')
downloadBlob(csv, 'hq-review-records.csv')
```

正确示例：

```ts
const res = await request.get('/api/hq/review/tasks/export', {
  params: currentFilters,
  responseType: 'blob',
})

downloadBlob(res.data, 'review-tasks-export.xlsx')
```

## 6. 选中导出说明

环节记录管理支持两种导出：

- 按筛选条件导出：`GET /api/hq/review/tasks/export`
- 按勾选记录导出：`POST /api/hq/review/tasks/export/selected`

选中导出请求：

```http
POST /api/hq/review/tasks/export/selected
Content-Type: application/json
```

请求体示例：

```json
{
  "task_ids": [35, 36]
}
```

兼容字段：

- `task_ids` / `taskIds` / `ids`：任务 ID，前端可直接传列表行里的 `task_id` 或 `id`。
- `service_item_ids` / `serviceItemIds`：环节服务项 ID；如果页面按单个服务环节勾选，优先传这个字段。

返回内容与筛选导出一致，仍是 XLSX 文件流，并嵌入压缩后的现场图片。
