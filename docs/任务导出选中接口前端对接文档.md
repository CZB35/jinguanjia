## 适用范围

本文只说明一个接口：

- `POST /tasks/export/selected`

这个接口用于任务列表页“勾选后导出”。

所有接口默认都挂在 `/api` 下。

## 1. 接口地址

```http
POST /tasks/export/selected
```

完整线上地址示例：

```text
https://service.ryds.cn/api/tasks/export/selected
```

## 2. 接口用途

用于前端在任务列表页勾选若干任务后，只导出选中的任务。

和原来的全量导出区别：

- 全量导出：`GET /tasks/export`
- 选中导出：`POST /tasks/export/selected`

## 3. 请求方式

请求头：

```http
Authorization: Bearer <access_token>
Content-Type: application/json
```

请求体：

```json
{
  "task_ids": [1, 2, 3]
}
```

字段说明：

- `task_ids`：任务主单 ID 数组，不能为空

## 4. 返回结果

返回的是文件流，不是 JSON。

### 4.1 文件类型

```text
application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
```

### 4.2 文件名

```text
tasks-export.xlsx
```

## 5. 导出内容

当前导出格式与全量导出保持一致：

- `xlsx`
- 中文表头
- 现场图片直接插入 Excel 单元格
- 不是图片链接

基础文本表头按客户要求固定为：

- `客户手机号`
- `客户姓名`
- `任务类型`
- `师傅姓名`
- `师傅手机号`
- `师傅评分`
- `门店`
- `经销商名称`
- `经销商评价`
- `客户评价`
- `客户地址`
- `师傅定位地址`

说明：

- `任务类型` 导出为中文，例如 `量尺服务`、`安装服务`、`熨烫服务`、`除尘除螨服务`
- `客户地址` 是任务客户地址。
- `师傅定位地址` 是师傅上传现场图片/视频时传入的位置；为空表示师傅端未传定位。

如果选中的任务里存在现场图片，还会动态增加：

- 最大图片数为 `1` 时：`附件图片`
- 最大图片数大于 `1` 时：`附件图片1`、`附件图片2`、`附件图片3` ...

按最大图片数自动扩展。插入的是压缩后的图片本体，不是 URL 链接。

## 6. 前端接法建议

### 6.1 勾选后调用

前端勾选任务后，直接传勾选行的任务主单 ID：

```json
{
  "task_ids": [101, 102, 103]
}
```

### 6.2 未勾选处理

前端建议先拦截：

```text
请先勾选要导出的任务
```

### 6.3 后端错误提示

如果请求体为空，后端会返回：

```text
task_ids不能为空
```

如果勾选任务最终没有可导出数据，后端会返回：

```text
所选任务暂无可导出数据
```

## 7. 与全量导出的关系

当前推荐：

- 导出当前筛选结果全部任务：`GET /tasks/export`
- 导出勾选任务：`POST /tasks/export/selected`

两者导出格式一致，只有选中范围不同。

## 8. 后端实现位置

- 路由注册：`src/routes/mod.rs`
- 接口实现：`src/routes/tasks.rs`

## 9. 建议联调方式

1. 任务列表页勾选 2-3 条任务
2. 调用：

```http
POST /tasks/export/selected
```

3. 确认下载成功
4. 打开 Excel 确认：

- 只包含勾选任务
- 表头为中文
- 服务类型、状态列为中文
- 有现场图片的任务，图片直接显示在表格里
