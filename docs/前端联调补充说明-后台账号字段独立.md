## 适用范围

本说明只覆盖后台账号体系的字段口径调整：

- 后台账号使用 `account + password` 登录
- `mobile` 只作为管理员联系电话/备注信息
- 经销商/师傅仍继续使用手机号体系

所有接口默认都挂在 `/api` 下。

## 1. 后台登录

后台登录请使用：

```http
POST /auth/login/admin
```

请求体示例：

```json
{
  "account": "zhangsan",
  "password": "123456",
  "role_code": "super_admin"
}
```

说明：

- 后台登录优先传 `account`
- 同时兼容 `username`
- 前端登录表单应展示为：
  - `账号`
  - `密码`

## 2. 后台账号管理 `/users`

后台账号管理继续使用：

- `GET /users`
- `POST /users`
- `GET /users/{id}`
- `PATCH /users/{id}`

### 当前字段口径

- `account`：后台登录账号
- `mobile`：管理员电话
- `name`：姓名

### 列表页字段映射

- “姓名” -> `name`
- “账号” -> `account`
- “管理员电话” -> `mobile`

## 3. 新增后台账号

接口：

```http
POST /users
```

请求体示例：

```json
{
  "account": "zhangsan",
  "mobile": "14725836913",
  "name": "张三",
  "password": "123456",
  "role_codes": ["super_admin"],
  "status": "active",
  "store_ids": [2]
}
```

### 说明

- `account`：后台登录账号，必填
- `mobile`：管理员电话，继续保留
- 后台账号只允许后台角色：
  - `super_admin`
  - `hq_reviewer`

## 4. 编辑后台账号

接口：

```http
PATCH /users/{id}
```

请求体示例：

```json
{
  "account": "zhangsan",
  "name": "张三",
  "email": "zhangsan@example.com",
  "avatar_url": "...",
  "role_codes": ["super_admin"],
  "store_ids": [2]
}
```

## 5. 经销商 / 师傅不受这次影响

### 经销商管理

仍按手机号体系：

- `GET /dealers`
- `POST /dealers`
- `GET /dealers/{id}`
- `PATCH /dealers/{id}`

这里的 `mobile` 仍然就是登录手机号。

### 师傅管理

仍按手机号体系：

- `GET /technicians`
- `POST /technicians`
- `GET /technicians/{id}`
- `PATCH /technicians/{id}`

这里的 `mobile` 也仍然就是登录手机号。

## 6. 前端最小改动清单

1. 后台登录页文案改成：

- `账号`
- `密码`

2. 调后台登录接口时，账号值放进请求字段：

```json
{ "account": "zhangsan", "password": "123456" }
```

3. 后台账号新增页：

- 新增 `account` 输入项
- `mobile` 字段展示文案改成“管理员电话”

4. 后台账号列表：

- “账号”列改读 `account`
- 不要再用 `mobile` 顶替账号列

5. 经销商/师傅页面不要套用这套后台账号字段逻辑。
