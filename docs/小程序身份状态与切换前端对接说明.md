# 小程序身份状态与切换前端对接说明

本文档说明小程序在经销商、师傅共用同一手机号时，如何处理身份启用/禁用和身份切换。所有接口默认带 `/api` 前缀。

## 核心结论

小程序不要自己判断手机号有哪些身份，也不要用本地缓存固定显示经销商/师傅入口。登录、刷新、查询当前用户时，以后端返回的 `user.roles`、`user.current_role`、`user.switchable` 为准。

后台现在区分两种状态：

- `user.status`：账号总状态，禁用后该手机号所有端都不能登录。
- `user_role.status`：身份状态，只控制某个身份，例如经销商身份或师傅身份。

经销商管理和师傅管理里的启用/禁用只影响对应身份，不影响同手机号下的其他身份。

## 登录返回字段

小程序业务端登录接口：

- `POST /api/auth/login/password`
- `POST /api/auth/login/code`

当前登录态有效期：

- 小程序业务端 `access_token` 固定 30 天。
- 小程序业务端 `refresh_token` 固定 30 天。
- `expires_in` 返回 `2592000` 秒。
- 后台登录接口 `POST /api/auth/login/admin` 不受影响，仍按后台 token 配置。
- `POST /api/auth/switch-role` 切换经销商/师傅身份后，也会返回 30 天有效期的新 token。

请求可选传 `role_code`。不传时，后端会自动选择一个可用身份。

```json
{
  "mobile": "13800000000",
  "password": "123456",
  "role_code": "technician"
}
```

返回重点字段：

```json
{
  "access_token": "xxx",
  "refresh_token": "xxx",
  "user": {
    "id": 1,
    "name": "李四",
    "mobile": "13800000000",
    "roles": ["dealer", "technician"],
    "current_role": "technician",
    "switchable": true,
    "status_code": "enabled"
  }
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `roles` | 当前账号可用的业务身份，只包含启用身份 |
| `current_role` | 当前 token 正在使用的身份 |
| `switchable` | 是否显示切换身份入口，等同于 `roles.length > 1` |
| `status_code` | 账号总状态，不代表某个身份状态 |

## 登录后本地保存

登录成功后，小程序需要整体覆盖本地登录态：

```js
const data = res.data.data
const user = data.user

wx.setStorageSync('access_token', data.access_token)
wx.setStorageSync('refresh_token', data.refresh_token)
wx.setStorageSync('roles', user.roles)
wx.setStorageSync('current_role', user.current_role)
wx.setStorageSync('switchable', user.switchable)
wx.setStorageSync('user', user)
```

不要把历史 `roles` 合并到新返回值里。后台禁用某个身份后，该身份会从新返回的 `roles` 中消失。

## 首页跳转规则

登录后按 `current_role` 跳转：

```js
const role = user.current_role

if (role === 'technician') {
  wx.reLaunch({ url: '/pages/technician/index' })
} else if (role === 'dealer') {
  wx.reLaunch({ url: '/pages/dealer/index' })
} else {
  wx.showToast({ title: '当前账号无可用身份', icon: 'none' })
}
```

如果 `roles` 只有 `["dealer"]`，只显示经销商端；如果只有 `["technician"]`，只显示师傅端。

## 身份切换入口

切换入口只根据后端返回的 `roles` 渲染：

```js
const roles = wx.getStorageSync('roles') || []

const canShowDealer = roles.includes('dealer')
const canShowTechnician = roles.includes('technician')
const switchable = roles.length > 1
```

不要根据手机号、用户名称、历史登录角色判断是否展示切换入口。

## 切换身份接口

切换身份调用：

```http
POST /api/auth/switch-role
Authorization: Bearer <access_token>
Content-Type: application/json
```

```json
{
  "role_code": "dealer"
}
```

或：

```json
{
  "role_code": "technician"
}
```

切换成功后，后端会返回新的 token 和新的 `current_role`。小程序必须整体覆盖本地登录态：

```js
const data = res.data.data
const user = data.user

wx.setStorageSync('access_token', data.access_token)
wx.setStorageSync('refresh_token', data.refresh_token)
wx.setStorageSync('roles', user.roles)
wx.setStorageSync('current_role', user.current_role)
wx.setStorageSync('switchable', user.switchable)
wx.setStorageSync('user', user)
```

然后按新的 `current_role` 跳转到对应首页。

## 进入小程序时校验当前身份

小程序冷启动或从后台恢复时，可以调用：

```http
GET /api/auth/me
Authorization: Bearer <access_token>
```

返回的 `roles` 和 `current_role` 仍然只包含当前可用身份。如果发现当前本地身份和接口返回不一致，以接口返回为准并覆盖本地缓存。

## 身份被后台禁用后的处理

如果后台禁用了当前 token 对应的身份，例如当前登录的是师傅身份，后台禁用了师傅身份：

1. 当前身份相关接口会返回登录失效或无权限。
2. 小程序清掉本地 token。
3. 跳转登录页。
4. 用户重新登录后，后端只返回仍启用的身份。

示例：同一手机号有经销商和师傅身份。

| 后台操作 | 登录后 `roles` | 小程序表现 |
| --- | --- | --- |
| 两个身份都启用 | `["dealer", "technician"]` | 显示切换入口 |
| 禁用经销商身份 | `["technician"]` | 只进师傅端 |
| 禁用师傅身份 | `["dealer"]` | 只进经销商端 |
| 账号总状态禁用 | 无法登录 | 提示账号被禁用 |

## 前端改造清单

1. 登录、切换身份、`/auth/me` 后都用返回值覆盖本地 `roles/current_role/switchable`。
2. 首页跳转只看 `current_role`。
3. 切换入口只看 `roles`，不要写死两个身份。
4. 接口返回登录失效时清登录态并回登录页。
5. 不要把 `status_code` 当成经销商或师傅身份状态，它是账号总状态。
