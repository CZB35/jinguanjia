## 适用范围

本文只说明师傅端现场视频上传规则。

所有接口默认都挂在 `/api` 下。

## 1. 接口

```http
POST /tasks/{id}/evidences/videos
```

示例：

```http
POST /api/tasks/1001/evidences/videos
```

## 2. 哪些环节可以上传视频

当前所有服务环节均支持上传视频：

- `量尺服务`：`measure`
- `安装服务`：`install`
- `熨烫服务`：`ironing`
- `除尘除螨服务`：`cleaning`

## 3. 请求参数

### 3.1 业务参数

这些字段现在既支持放在 query，也支持放在 `multipart/form-data` 文本字段。

前端推荐直接跟视频文件一起放在 `form-data`。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `execution_id` | number | 推荐 | 开始执行接口返回的执行记录 ID |
| `service_item_id` | number | 否 | 服务环节子项 ID |
| `service_type` | string | 否 | 服务环节 |
| `location_address` | string | 建议传 | 师傅当前定位地址文本 |

### 3.2 表单参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | file | 是 | 视频文件 |
| `execution_id` | text | 否 | 执行记录 ID，推荐传 |
| `service_item_id` | text | 否 | 服务环节子项 ID |
| `service_type` | text | 否 | 服务环节 |
| `location_address` | text | 否 | 师傅当前定位地址文本 |

## 4. 水印规则

视频上传时，后端会先给视频打水印，再保存原文件。

大小限制：

- 单个现场视频不能超过 `50MB`

地址规则：

1. 如果传了 `location_address`
   - 视频水印优先使用师傅定位地址
2. 如果没传 `location_address`
   - 视频水印回退使用客户地址

也就是说：

- 后续查看附件
- 下载附件
- 批量下载附件

看到的都是已经固化好水印的视频文件。

## 5. 部署要求

服务端需要安装 `ffmpeg` 才能处理视频水印。

如果部署机没有安装 `ffmpeg`，视频上传会失败。

如果需要自定义路径，可配置环境变量：

```text
FFMPEG_PATH
```

## 6. 一句话结论

师傅端现场视频上传目前支持所有服务环节，并且视频会在上传时直接打好水印。
