## 适用范围

本说明只覆盖后台管理端与业务端角色隔离相关的联调变更。

目标：

- 后台登录与业务端登录分离
- 后台角色管理页不再展示经销商、技师角色
- 后台账号管理页不再混入经销商、师傅账号

所有接口默认都挂在 `/api` 下。

## 1. 后台登录接口

后台管理端请改用：

```http
POST /auth/login/admin
Content-Type: application/json
```

请求体示例：

```json
{
  "mobile": "admin",
  "password": "yy123456!",
  "role_code": "super_admin"
}
```

### 说明

该接口只允许以下后台角色登录：

- `super_admin`
- `hq_reviewer`

如果账号只有以下业务角色，将返回无后台权限：

- `dealer`
- `technician`

## 2. 原通用登录接口用途调整

原接口仍然保留：

```http
POST /auth/login/password
```

### 用途

- 业务端
- 小程序端
- 经销商端
- 师傅端

### 前端要求

后台管理端不要再使用这个接口登录。

## 3. 角色管理页

接口：

```http
GET /system/roles
```

### 当前变化

后端已经隐藏以下业务角色：

- `dealer`
- `technician`

所以后台角色列表页只会展示后台角色。

### 前端处理

角色管理页直接使用接口返回结果即可，不需要前端再手动过滤。

## 4. 后台账号管理列表

接口：

```http
GET /users
```

### 当前变化

后端现在只返回后台账号，也就是至少拥有以下角色之一的账号：

- `super_admin`
- `hq_reviewer`

经销商、师傅账号不会再出现在后台账号管理列表中。

### 当前字段

列表项中已包含：

- `name`
- `account`
- `mobile`

建议映射：

- “姓名”列 -> `name`
- “账号”列 -> `account`
- “管理员电话”列 -> `mobile`

## 5. 后台账号新增/编辑

接口：

```http
POST /users
PATCH /users/{id}
```

### 当前规则

后台账号只允许分配后台角色：

- `super_admin`
- `hq_reviewer`

如果传入：

- `dealer`
- `technician`

后端会直接返回错误：

```text
后台账号仅允许分配后台管理角色
```

### 前端要求

后台账号新增/编辑页里的角色选择，不要再给出业务角色：

- 经销商
- 技师

## 6. 推荐前端最小改动清单

1. 后台登录页改用：

```http
POST /auth/login/admin
```

2. 角色管理页继续调：

```http
GET /system/roles
```

但直接使用返回结果，不再自行混入业务角色。

3. 后台账号列表继续调：

```http
GET /users
```

4. 后台账号新增/编辑页角色选项只保留后台角色。
