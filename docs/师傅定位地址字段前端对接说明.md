# 师傅定位地址字段前端对接说明

## 背景

现场图片/视频上传时，后端会保存师傅端传入的当前位置地址。前端展示任务详情、环节记录详情和导出数据时，需要区分“客户地址”和“师傅定位地址”。

## 字段定义

| 字段 | 含义 | 为空规则 |
| --- | --- | --- |
| `customer_address` | 客户服务地址 | 按任务绑定的客户地址返回 |
| `technician_location_address` | 师傅上传现场图片/视频时的定位地址 | 师傅未传、传空字符串、只传空格时返回空字符串 |

注意：水印可以在未传定位时兜底显示客户地址，但接口里的 `technician_location_address` 不会用客户地址兜底。

## 返回该字段的接口

### 任务列表

`GET /api/tasks`

每条 `items[]` 增加：

```json
{
  "address": "河北省石家庄市长安区123",
  "technician_location_address": "临颍县荣耀授权专卖店"
}
```

其中 `address` 仍是原来的客户地址字段。

### 任务详情

`GET /api/tasks/{id}`

`GET /api/tasks/{id}/detail`

响应根节点增加：

```json
{
  "customer_address": "河北省石家庄市长安区123",
  "technician_location_address": "临颍县荣耀授权专卖店"
}
```

原有 `customer.address` 保留不变。

### 环节记录列表

`GET /api/hq/review/tasks`

`GET /api/hq/review/tasks/pending-and-completed`

`GET /api/hq/review/tasks/pending-execute-and-executing`

每条 `items[]` 增加：

```json
{
  "customer_address": "河北省石家庄市长安区123",
  "technician_location_address": "临颍县荣耀授权专卖店"
}
```

### 环节记录详情

`GET /api/hq/review/tasks/{id}`

`GET /api/hq/review/tasks/{id}/detail`

响应根节点增加：

```json
{
  "customer_address": "河北省石家庄市长安区123",
  "technician_location_address": "临颍县荣耀授权专卖店"
}
```

## 导出字段

### 任务导出

`GET /api/tasks/export`

`POST /api/tasks/export/selected`

导出 XLSX 增加两列：

- `客户地址`
- `师傅定位地址`

### 环节记录导出

`GET /api/hq/review/tasks/export`

导出 CSV 增加两列：

- `客户地址`
- `师傅定位地址`

## 前端展示建议

- 详情页原“服务地址”继续展示客户地址，字段用 `customer_address` 或原 `customer.address`。
- 新增一行“师傅定位地址”，字段用 `technician_location_address`。
- 如果 `technician_location_address` 为空，显示 `--`，不要显示客户地址。
