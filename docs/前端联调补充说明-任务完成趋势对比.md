## 适用范围

本说明只覆盖工作台里的“任务完成趋势对比”图表对接。

所有接口默认都挂在 `/api` 下。

## 1. 使用现有工作台接口

继续使用现有接口，不需要新开接口：

- `GET /hq/dashboard`
- `GET /dealer/dashboard`
- `GET /technician/dashboard`

## 2. 新增查询参数

支持：

```text
trend_mode=week | month | year
```

例如：

```http
GET /hq/dashboard?trend_mode=week
GET /hq/dashboard?trend_mode=month
GET /hq/dashboard?trend_mode=year
```

不传时默认：

```text
week
```

## 3. 新增返回字段

返回里新增：

```json
task_trend_compare: []
```

每项结构：

```json
{
  "period": "第1天",
  "completed_count": 0,
  "total_count": 0
}
```

## 4. 前端图表映射

图表两条线：

- `已完成任务` -> `completed_count`
- `任务总量` -> `total_count`

X 轴：

- `period`

## 5. 周 / 月 / 年返回格式

### week

返回最近 7 个点，`period` 示例：

```text
周一
周二
周三
周四
周五
周六
周日
```

### month

返回最近 30 个点，`period` 示例：

```text
1日
2日
...
30日
```

### year

返回最近 12 个点，`period` 示例：

```text
1月
2月
...
12月
```

## 6. 图表映射示例

前端可直接按下面方式映射：

```ts
const points = dashboard.task_trend_compare

const xAxis = points.map(item => item.period)
const completedSeries = points.map(item => item.completed_count)
const totalSeries = points.map(item => item.total_count)
```

对应图例：

- `已完成任务` -> `completedSeries`
- `任务总量` -> `totalSeries`

## 7. 前端最小改动

1. 周 / 月 / 年切换时，重请求当前 dashboard 接口，并带：

```text
trend_mode=week/month/year
```

2. 图表数据源改读：

```json
task_trend_compare
```

3. 映射规则：

- 横轴：`period`
- 线1：`completed_count`
- 线2：`total_count`
